## Agent skills

### Issue tracker

Issues live in this repository's GitHub Issues; use `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. See `docs/agents/domain.md`.

### Storyboard illustrations

- Use existing downloadable Storyset SVGs for characters and illustrated situations. Any Storyset style may be used when it fits; prefer visual continuity with nearby scenes.
- Do not generate character art or draw characters from scratch. Adapt existing Storyset character SVG shapes as needed to fit the scene while keeping the source character recognizable and retaining its visual style.
- Add audience-facing text, score cards, and backgrounds as separate composition layers around the source illustration.
- When a character holds a paper for themselves, orient the paper toward the character; put audience-readable grades or notes in a separate overlay.
- Credit each Storyset asset with its source link in the storyboard.

### Animation scene frames

- A standalone scene frame contains only the on-screen composition: its background, source illustration, props, overlays, and text that are part of the animation.
- Keep production-board titles, section labels, timestamps, footers, legends, asset credits, and production notes outside the scene artwork, in the storyboard page or document.
- Put the requested on-screen text in the final frame of a scene sequence unless the script calls for it earlier.

### Storyboard animation

- For any storyboard animation, read `docs/agents/story-animation.md` before planning transitions, object entrances, secondary object or body motion, music, or sound effects.
