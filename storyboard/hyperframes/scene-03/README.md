# Scene 3 · HyperFrames source

This 50-second editable composition contains three separate 15-second cases and a 5-second end card. It is loaded as the second player on `../motion.html`, beside Scene 2.

The narration captions reproduce `Script Video Kode Etik.pdf` verbatim and appear one word at a time with a mustard active-word tween. The project reuses the credited ambient track and CC0 sound effects documented in [`../AUDIO_CREDITS.md`](../AUDIO_CREDITS.md).
